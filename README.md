# تطبيق إدارة الخدمات الطبية

تطبيق أندرويد أصلي (Flutter) مرتبط بـ API الموقع.

## التحميل

من صفحة الإصدارات Releases حمّل الملف `msd-mobile-v1.0.0.apk`.

## التثبيت

1. فعّل «تثبيت من مصادر غير معروفة» إن طلب الجهاز ذلك
2. افتح ملف APK وثبّته
3. في الإعدادات داخل التطبيق ضع عنوان الخادم (API) إن لزم
