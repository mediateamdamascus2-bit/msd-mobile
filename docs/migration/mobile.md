# اختبار تطبيق الجوال بعد التحويل إلى React

شغّل الخادم على الجهاز، وثبّت نسخة debug على المحاكي (العنوان الافتراضي `http://10.0.2.2:5148`) أو هاتف على نفس الشبكة بعنوان محلي. نسخة release لا تقبل إلا `https://`.

## دخول كل نوع حساب

- [ ] مدير النظام (`admin`) يفتح لوحة القيادة.
- [ ] مسؤول مشفى حرستا (`harasta`) يفتح لوحة المشفى.
- [ ] مسؤول سجن حسيا (`hasia`) يفتح لوحة السجن.
- [ ] حجز المواعيد يفتح محطة الحجز.
- [ ] الاستقبال يفتح طابور الاستقبال.
- [ ] عيادة (مثل القلبية) تفتح طابور تلك العيادة.
- [ ] قسم (مخبر أو صيدلية) يفتح محطة القسم.
- [ ] محطات حسيا: استقبال النزيل، الفرز، الحالات، الصيدلية الداخلية، الصيدلية الخارجية. كل حساب يفتح محطته.
- [ ] سائق الأسطول (`/fleet/driver/{id}`) يفتح شاشة مهامه.
- [ ] نقطة الميدان تفتح واجهتها.
- [ ] حساب قديم ما زال مساره `/stations/...` يصل إلى المحطة نفسها.

## فتح المحطة الصحيحة

- [ ] بعد الدخول، الشاشة الأولى هي محطة `homePath` وليست لوحة عامة.
- [ ] مسار `/hospitals/{hid}/station/{kind}/{name}` يفتح محطة ذلك المشفى.
- [ ] مسار `/prisons/hasia/station/{station}` يفتح محطة السجن المطابقة.
- [ ] مسار `/fleet/driver/{id}` يفتح مهام ذلك السائق.

## استدعاء مريض

- [ ] من الاستقبال أو العيادة، استدعِ المريض التالي.
- [ ] يظهر اسم المريض في الطابور، ويختفي من قائمة الانتظار أو تنتقل حالته.

## صرف دواء

- [ ] من صيدلية المشفى أو صيدلية حسيا، اصرف دواءً لمريض أو نزيل موجود.
- [ ] تنقص الكمية في المخزون، ويظهر الصرف في سجل المريض.

## انتهاء الجلسة

- [ ] اترك التطبيق حتى يرفض الخادم التوكن، أو أبطل الجلسة من الإدارة.
- [ ] يطلب التطبيق التجديد مرة واحدة من `/api/auth/refresh`.
- [ ] إذا فشل التجديد، تُمسح الجلسة وتظهر «انتهت الجلسة — سجّل الدخول من جديد».

## تعطيل الحساب أثناء الاستخدام

- [ ] عطّل الحساب من إدارة الحسابات بينما التطبيق مفتوح واطلب أي بيانات.
- [ ] تظهر «هذا الحساب معطّل. راجع مسؤول النظام.» ويعود التطبيق إلى الدخول.
- [ ] محاولة الدخول بكلمة المرور الصحيحة تعرض الرسالة نفسها ولا تفتح محطة.

## الخروج

- [ ] اضغط «خروج».
- [ ] يُستدعى `/api/auth/logout`، وتُمسح الرموز، وتعود شاشة الدخول.
- [ ] إعادة فتح التطبيق لا تدخل الحساب تلقائياً.
